# AGENTS.md

Interactive grade-4 math ebook ("Faktor dan Kelipatan", Indonesian UI). Created by Nata. Students sign in with name/class/absent number, progress through sequentially unlocked steps earning points, and teachers view/download a CSV recap.

## Stack

TanStack Start (React 19, file routes), Tailwind CSS 4 with theme variables in `src/styles.css`, shadcn/ui in `src/components/ui`, Netlify Database (Postgres) via Drizzle ORM (`drizzle-orm@beta`), deployed on Netlify.

## Layout

```
db/schema.ts                 # students (per-step points) + answers (unique per student/question)
db/index.ts                  # Drizzle client (drizzle-orm/netlify-db)
netlify/database/migrations/ # Generated by drizzle-kit; applied by Netlify on deploy
src/lib/module.ts            # Single source of truth: steps, point values, questions (no answer key), unlock rules
src/server/answer-key.ts     # Correct options; only imported by server function handlers
src/server/ebook.functions.ts# All server functions: student start/progress/complete, quiz answers, teacher recap/delete
src/routes/index.tsx         # Welcome/sign-in + Reader shell (step nav, auto-advance)
src/routes/guru.tsx          # Teacher PIN login, recap table, CSV export (built client-side)
src/components/ebook/        # One component per step (Video, Factor, Multiple, Game, Quiz, Report) + shared bits
public/img/                  # Generated mascot (Kak Owi) and hero illustration, served through Netlify Image CDN (cdn() helper)
```

## Decisions

- Server enforces step order and fixed point values; client only reports "completed" events. Game points = max(10, 20 − mistakes).
- Answers are immutable: `answers` has a unique index on (student_id, question_no) and inserts use `onConflictDoNothing`.
- Student identity is a random token in `localStorage`; signing in again with the same name + class + absent number resumes the record.
- Teacher PIN comes from the `TEACHER_PIN` env var (default `1234`) and is re-checked in every teacher server function; the client keeps it in `sessionStorage`.
- Video completion uses the YouTube IFrame API and counts unique seconds actually played (≥85%), so seeking ahead doesn't count.
- Reading pages unlock their finish button after the reader scrolls to the bottom and spends 20 seconds.

## Conventions

- UI copy is Indonesian, aimed at 9–10 year olds: big tap targets, `font-display` (Fredoka) headings, Nunito body.
- Use theme color classes (`primary`, `secondary`, `accent`, `grape`, `success`) rather than raw colors.
- Schema changes: edit `db/schema.ts`, then `npx drizzle-kit generate --name <verb_description>`. Never hand-edit applied migrations.
- Point values or questions change in `src/lib/module.ts` (and the key in `src/server/answer-key.ts`).
